# 대표님을 위한 AI 활용 연수 · 복기 사이트 (2026.11.12)

2026년 11월 12일 인천창조경제혁신센터에서 진행한 「대표님을 위한 AI 활용 연수」의 내용을 다시 볼 수 있게 정리한 정적 사이트입니다.

- 주소: https://j333333766-hub.github.io/aizen-1112-review/
- 구성: 처음(오늘 기분) → 1 시작 설문·AI 이해 → 2 일상 활용 → 3 수업·평가 → 4 일터의 AI → 5 유지보수 접수 앱 → 6 질문과 마무리
- '직접 해 보기' 체험 11가지는 브라우저 안에서만 움직입니다(저장·전송·AI 호출 없음).
- 현장 결과(기분·설문·실시간 수업·질문 벽)는 이름·소속과 연결되지 않은 합계만 `js/data.js`에 실었습니다.
- 화면 속 회사·사람·숫자는 가상입니다.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 첫 화면 |
| `js/content.js` | 단계별 연수 내용 |
